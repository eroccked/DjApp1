# DjApp1 — Меню ресторану на Django

Навчальний вебзастосунок на **Django 6.1** для перегляду та керування меню ресторану: страви, категорії, реєстрація та вхід користувачів, редагування меню для персоналу.

## Можливості

- **Головна сторінка** та **список меню** — показуються лише страви, які є в наявності.
- **Детальна сторінка страви** — назва, опис, ціна, категорія.
- **CRUD для страв** (додавання, редагування, видалення) — доступно лише персоналу (`is_staff`) через декоратор `staff_required`.
- **Акаунти**: реєстрація, вхід, вихід (стандартні `auth`-в'юхи Django).
- **Адмін-панель** з фільтрами, пошуком та редагуванням ціни/наявності прямо у списку.
- Інтерфейс українською (`LANGUAGE_CODE = 'uk'`, часовий пояс `Europe/Kyiv`).

## Структура проєкту

```
DjApp1/
├── config/          # налаштування проєкту (settings, urls, wsgi, asgi)
├── menu/            # застосунок меню: моделі Category, Dish, форми, в'юхи, шаблони, статика
├── accounts/        # реєстрація / вхід / вихід
├── manage.py
└── requirements.txt
```

## Моделі

| Модель     | Поля |
|------------|------|
| `Category` | `name` |
| `Dish`     | `name`, `description`, `price`, `category` (FK → Category), `is_available`, `created_at` |

## Маршрути

| URL                       | Опис                     | Доступ    |
|---------------------------|--------------------------|-----------|
| `/`                       | Головна                  | всі       |
| `/menu/`                  | Список страв             | всі       |
| `/menu/<id>/`             | Деталі страви            | всі       |
| `/menu/add/`              | Додати страву            | персонал  |
| `/menu/<id>/edit`         | Редагувати страву        | персонал  |
| `/menu/<id>/delete`       | Видалити страву          | персонал  |
| `/accounts/register/`     | Реєстрація               | всі       |
| `/accounts/login/`        | Вхід                     | всі       |
| `/accounts/logout/`       | Вихід                    | авторизовані |
| `/admin/`                 | Адмін-панель             | суперкористувач |

## Встановлення та запуск

```bash
git clone <url-репозиторію>
cd DjApp1

python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt

python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Відкрийте http://127.0.0.1:8000/

> База даних `db.sqlite3` не зберігається в репозиторії — вона створюється командою `migrate`. Категорії та страви додайте через `/admin/`.

## Технології

- Python 3.14
- Django 6.1.2
- SQLite
